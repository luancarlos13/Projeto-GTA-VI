## 🎮 PROJETO GTA VI — DEV CITY

## 📌 Sobre o Projeto

O Projeto GTA VI é uma página web interativa inspirada no universo de Grand Theft Auto VI, desenvolvida com o objetivo de explorar conceitos de desenvolvimento Front-End, criação de interfaces visuais e interatividade com JavaScript.

A proposta do projeto é apresentar uma experiência inspirada na identidade visual do jogo, permitindo que o usuário escolha seu personagem favorito por meio de avatares interativos.

A interface apresenta personagens como Lucia, Jason, CJ e uma versão personalizada minha, trazendo uma experiência descontraída e uma identidade visual própria.

## 🚀 Funcionalidades

- 🎭 Seleção de Personagens: possibilidade de escolher entre diferentes personagens disponíveis na interface.
- 🖼️ Troca Dinâmica de Imagens: ao selecionar um personagem, sua imagem principal é atualizada automaticamente.
- 🎨 Alteração de Cores: cada personagem possui uma cor de identificação que acompanha sua seleção.
- 🧿 Interface Interativa: menu de seleção com avatares clicáveis.
- 🌆 Identidade Visual Temática: layout inspirado no universo de GTA VI, com elementos visuais e tipografia característica.
- 📱 Design Responsivo: adaptação da interface para diferentes tamanhos de tela, incluindo computadores e dispositivos móveis.

## 🎯 Objetivo

Este projeto faz parte da minha jornada de aprendizado e evolução no desenvolvimento Front-End. A ideia foi transformar uma referência do universo dos games em uma experiência web interativa, colocando em prática conhecimentos de HTML, CSS e JavaScript.

Cada projeto representa uma nova oportunidade de aprender, experimentar e desenvolver minhas habilidades como programador.
